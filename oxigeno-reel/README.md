# O2 · ASCII LAB

Prueba editorial vertical de 20 segundos. Escenografía procedural, muestreada y renderizada con caracteres a color. Sonido electrónico sintetizado; sin voz. Exportación H.264/AAC a 1080×1920, 24 fps; gráfico base a 540×960 escalado para conservar el carácter tipográfico. No utiliza imágenes o videos generados por IA.

- Abrir index.html para reproducir y saltar entre escenas.
- Publicar toda esta carpeta en GitHub Pages; ruta /oxigeno-reel/.
- Video independiente: oxigeno-20s.mp4.
- Regenerar: python3 render.py (requiere Pillow, FFmpeg y la fuente Noto Sans Mono indicada en el script).

## Guion y límites

Escenario ficticio: desaparece solo el O2 molecular del aire y retorna tras 20 segundos. Se conserva el oxígeno químicamente ligado al agua y a los materiales. No se modela la dinámica atmosférica ni la caída de presión. El reloj y el montaje comprimen la explicación; los cortes no son una predicción de tiempos de síntomas. Las señales del cuerpo son ilustrativas, no lecturas médicas. No se representa un apagón eléctrico universal.

1. Ciudad y composición del aire.
2. Extinción de llamas dependientes del oxígeno del aire.
3. Peligro de hipoxia, sin momento universal de desmayo.
4. Persisten edificios y agua; retorno del O2 no elimina automáticamente las consecuencias.
